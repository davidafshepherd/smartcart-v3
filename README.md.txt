# SmartCart v3

On-device meal analysis app:
- Frontend: Next.js (dashboard)
- Backend: FastAPI + PyTorch (OWLv2 + SAHI + SAM2)
- DB: Cloud Postgres (accessed from backend)

## Structure

- `frontend/` – Next.js dashboard
- `backend/` – FastAPI API + ML pipeline
- `docs/` – architecture diagrams, API contracts, notes
